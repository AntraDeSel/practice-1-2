##  Шаг 3: Описание заданий

### Задание 1: Разминка. Базовое сужение типов (30 мин)
**Файл:** `src/task1-narrowing.ts`
**Задача:** Вспомнить, как компилятор сужает типы внутри блоков `if`.
- `describeValue`: используйте `typeof` для различения `string`, `number` и `boolean`.
- `formatError`: используйте `instanceof` для различения объекта `Error` и обычной строки.
- `moveAnimal`: используйте оператор `in` (например, `"swim" in animal`), чтобы понять, кто перед нами — рыба или птица.
**Проверка:** `npm test -- task1`

### Задание 2: Type Predicates (50 мин)
**Файл:** `src/task2-predicate.ts`
**Задача:** Написать функцию-предикат, которая проверяет структуру объекта в рантайме и "обещает" это компилятору.
- Реализуйте `isTransaction(data: unknown): data is Transaction`. Проверьте, что `data` — это объект, не равен `null`, и содержит поля `id` (строка), `amount` (число) и `type` (одна из двух строк).
- Реализуйте `processTransaction`, которая использует этот предикат.
**Важно:** В JavaScript `typeof null` возвращает `"object"`. Не забудьте явно проверить `data !== null` перед тем, как обращаться к полям!
**Проверка:** `npm test -- task2`

### Задание 3: Assertion Functions (40 мин)
**Файл:** `src/task3-assertion.ts`
**Задача:** Написать функцию, которая бросает ошибку, если данные невалидны, и сужает тип для всего кода после неё.
- Реализуйте `assertValidConfig(data: unknown): asserts data is AppConfig`. Если данные не соответствуют конфигурации — бросьте `new Error("Invalid config")`.
- Реализуйте `initApp(config: unknown)`, которая сначала вызывает assertion-функцию, а потом работает с конфигом как с типом `AppConfig`.
 **Подсказка:** Assertion Function ничего не возвращает (не пишите `return true/false`). Она либо молча пропускает код дальше, либо бросает ошибку.
**Проверка:** `npm test -- task3`

### Задание 4: Мини-проект. Парсер сырых данных (60 мин)
**Файл:** `src/task4-parser.ts`
**Задача:** Синтез всех знаний. Представьте, что вы получили массив данных из внешнего API (`unknown[]`).
1. Скопируйте или напишите заново предикат `isTransaction`.
2. Реализуйте `parseTransactions(rawData: unknown[])`, которая проходит по массиву и разделяет данные на два массива: валидные транзакции (`valid`) и строки с описанием ошибок (`errors`).
3. Реализуйте `calculateBalance(transactions: Transaction[])`, которая считает итоговый баланс (deposit прибавляет, withdrawal вычитает).
**Проверка:** `npm test -- task4`

##  Частые проблемы и решения

- **Ошибка компиляции в тестах, хотя я всё написал:**
  Помните, что сужение типов работает **только внутри блока `if`**. Если вы сужаете тип в одной функции, а используете в другой — компилятор об этом не знает. Нужно использовать Type Predicates.
- **Тесты падают с ошибкой "Cannot read properties of null":**
  Это ошибка рантайма. Скорее всего, вы забыли проверить `data !== null` перед тем, как делать `typeof data.something` или обращаться к полям объекта.
- **VS Code подчеркивает код красным, но тесты проходят:**
  Нажмите `Ctrl + Shift + P` (или `Cmd + Shift + P` на Mac), введите `Restart TS server` и нажмите Enter.
